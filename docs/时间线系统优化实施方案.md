## 1. 已验证的事实（不要再按报告改反）

审查报告有几处与游戏素材不符，已用剧本原文核对（见 `src/timeline/chapters.rs` 测试）：

1. **报告说 310x=雪菜、320x=和纱，实际相反。**
   - 3103: 「だから、かずさを選んだ。」3109: 「五年前に、君じゃなくてかずさを選んだ…」
     → 31xx = **和纱**线。
   - 3211 是向雪菜求婚的场景（「俺とつきあってください………一生涯」）→ 32xx = **雪菜**线。
   - 所以当前 `coda_kazusa = 3101..3111`、`coda_setsuna = 3201..3211` 是**对的**，
     报告建议的互换是错的。测试里已经钉住，禁止"按报告修反"。
2. **2020..2033 不是 CC-共通，是 CC 的雪菜主线**（2019 的四分支：2020 雪菜主线 / 2301 小春 /
   2401 千晶 / 2501 麻理；2033 → 3001 CODA）。`cc_common` 只到 2019。保持现状。
3. **2025 不是凭空特例**：2020–2023 每个都有 `→ 2025` 的岔路，2025 是 CC 雪菜线的
   一个结局（dead end），属于 `终章 · 雪菜` 章节。不要把它丢进"其他"。
4. **5000–5004 与 5100–5104 都是电子小说**（正文首句分别是「特別編 二年前」「序章 一月後の、あの娘」）。
   统一显示标题「电子小说」，但两条链分属不同 lane（5xxx 与 51xx 是两条独立链，不能同 lane 并列）。
5. 子剧本跳转已经并入入口节点（graph.rs 遍历所有 .bnr、entry_of 归并），IC 链
   1008→1009→…→1013 是通的；当前 roots 只有 1001 / 5000 / 5100。
6. 当前 graph 结构：163 节点、9 个分支点、11 个结局、0 个悬空跳转。用
   `./target/release/wa2-native timeline-check` 可复现。

## 4. 画布与坐标约定

- 逻辑画布 1280×720；顶部 banner 0..40；章节 header 条 42..66；图表 CHART_TOP=72；
  预览条 PREVIEW_TOP=524（高 196）；底部 pager 由素材 `sys_06021` 决定。
- 节点 104×59，PITCH_X=136，PITCH_Y=72；`nav::place` 负责世界坐标 → 屏幕坐标。
- 章节 = 章节表的一项；band 是它在 x 方向的跨度（列 $\times$ PITCH_X）。
- paint 里文字：`preview::label` 预生成 Label（白色覆盖度），`paint::blit_tinted` 上色。
  不要在每帧里重复光栅化大段文字；header 已经由 run 循环预生成放进 `PaintState.headers`。
