## 2. 方法与工具

新增 `tools/lscr_dump.py`（随本报告入库），按引擎 `Program::load` 相同规则解码 op 流：

```
Rec  : 6, kind          记录开始（K30 普通 / K16 立绘上屏 / K23 结构 / K18 …）
Val  : 5, type, value   int(type=3) / float(type=4)，记录内累积
Tok  : 3, N            引用 .txt 字符串池第 N 项
Act  : 4, ID           页面/舞台动作
跳转 : 0,12,T=goto；0,2,A,B=二路分支；0,1=return
```

复现：`python3 tools/lscr_dump.py 1002 1200`
实测场景：1001（IC 开场）、1002（轻音部教室）、1003、1006/1007（ACT176 样本）、2001。

`.txt` 是逗号分隔字符串池：台词、说话人、文件名、脚本号混在一起，字节码只存下标。

## 3. 页面模型：一页 = 一次点击 = 4 条记录

场景 1002 实测（每页严格重复此结构）：

```
Rec K30: TOK[1]『武也』        ACT144   ← 名牌（TOK 缺省 = 清空名牌 → 旁白模式）
Rec K30: (10, …)              ACT138   ← 语音参数 + 说话焦点（谁说话谁亮）
Rec K30: TOK[2]『ちょっ、ちょっと待てって！…』 ACT131  ← 正文上屏
Rec K30: (1, …)               ACT132   ← 等玩家点击
```

**字节码位置 = 生效时机**：舞台指令插在第 N 页的 `ACT132` 与第 N+1 页的 `ACT144` 之间，就精确地在"点过第 N 页之后"生效。这是原版"哪段剧情配什么文本/立绘/背景/语音"的全部控制方式——没有任何外部时间轴。

## 4. 舞台指令详解

### 4.1 背景：ACT146 / ACT147（新发现，引擎未实现）★P0

记录格式：`K30 vals=(模式, 背景ID, 变体?, 过渡帧数, 0, 0, 0, 1280.0, 720.0)`，末尾两个 float 是全屏尺寸。

- **ID → 文件**：`b{ID}00.tga`。已验证 16 个 ID 中 11 个直接命中
  （`b100400/b100500/b100600/b100700/b100800/b101000/b101300/b102400/b104000/b106000/B990000` 均存在于 `data/bg`）
- **变体后缀**：`b1028 → b102802.tga`、`b1035 → b103502.tga`（无 `00` 版）→ 匹配策略：`b{ID}00.tga` 优先，`b{ID}*` 前缀兜底；变体位来源待查
- **特殊值**：`ID=0` 与 `ID=-2`（0xFFFFFFFE）→ 黑屏；`ID=9900` → `B990000.tga`（专用黑图，2001 实证）
- **模式位**：常态为 1，亦见 12 / 128 / 158 / 178 / 198 —— 高位疑为过渡效果标志（闪白等），待挖
- 146 与 147 的分工未定（疑：带淡入 vs 硬切/交叉溶解）

1002 开场实测序列：


### 4.2 立绘：K30 选脸 + K16 上屏（部分实现，缺站位）★P0

成对出现：

```
Rec K30: vals=(char_id, 差分variant, 系列×1000)   ← 选哪张脸，无 Act
Rec K16: vals=(slot, 0, [0, 15,] 256, 128) ACT154/155  ← 怎么上屏
```

- 文件名 `{prefix}{系列:03}{差分:03}.tga`（前缀表已从 exe 偏移 661252 提取，工作区未提交）
- **slot = 站位，且是动态的**：实测 1002 中 親志(12)→slot 0、武也(10)→slot 1、雪菜(2)→slot 2、教師(17, 系列2)→slot 2；同一角色随舞台调度**换槽移动**（雪菜先后出现在 slot 2 与 slot 1）
- **ACT154 vs 155**：154 常见 6 参数（多出 `0, 15`，疑过渡方式），155 常见 4 参数；语义疑为"原位换表情" vs "登场"。待实机对照确认
- **退场指令未发现**：扫描未见无 K30 前导的独立 K16（疑退场走特定参数组合或其它记录类型），待挖

### 4.3 物品/叠层 CG：ACT176（**当前被误当背景**）★P0 根因

记录格式：`K30 vals=(slot, ?, 2, 256, flag) toks=[文件名, '', 目录] ACT176`，目录 ∈ {`grp`, `bak`}。

实测样本：

| 场景 | vals | toks | 含义 |
|---|---|---|---|
| 1006 | (0, 14, 2, 256, 1) | `ギター.tga` / grp | 吉他道具 CG，进 0 号叠层槽 |
| 1007 | (1, 13, 2, 256, 1) | `b105300.tga` / bak | 背景图进 1 号槽（叠层用法） |
| 2001 | (0, 15, 2, 256, 0) | `B990000.tga` / bak | 黑图 |
| 2001 | (0, 3, 2, 256, 0) | `f0040.bmp` / grp | 效果图 |

**结论**：ACT176 是 slot 制的图层加载（道具/叠层/效果），不是背景切换指令。引擎现把它的首个 `.tga` 当全屏背景 → 道具图突然整屏替换 = 验收所见的"背景错乱"。

### 4.4 BGM / SE：原版 exe 核对后的修正

此前将 ACT165 解释为 BGM、将 ACT158 解释为旁白语音，均为错误推测。以 WA2.exe 指令处理函数及资源文件名为依据：

- ACT158 → `0x455400` → `0x40fa50` → `0x40f970`：BGM，参数 `(曲号, 淡入帧数, 循环, 音量[,附加参数])`。曲号直接用于 `BGM_%03d.ogg`，不存在减 1000 的映射。文件读取函数 `0x460e10` 优先无后缀，再按内部参数选择 `_a` / `_b`。
- ACT159 → `0x455430`：停止 BGM；ACT161 → `0x455460`：调整 BGM 音量，带过渡帧数。
- ACT164 → `0x4554c0`：独立短音效 `(SE编号, 音量)`。
- ACT165 → `0x4554e0` → `0x40f2d0`：声道音效 `(声道, SE编号, 淡入帧数, 循环模式, 音量, 附加模式)`。编号直接查 `SE_%04d.WAV` / `.OGG`，包括 1013、1908、2900、2912、8159、8160、9702。
- ACT166：停止指定 SE 声道，带淡出帧数；ACT167：调整 SE 声道音量；ACT168：等待声道结束。
- 场景1001使用 `ACT158(8,-2,1,255)`，场景1002使用 `ACT158(3,180,1,255)`。后者应播放第3首，ACT165的1013不能切换为第13首。

当前实现分流 BGM/SE 并处理音量过渡，导入 SE.PAK。尚未完整实现：BGM特殊切换参数（-2在原版还令旧声道15帧淡出）、A/B内部选择、ACT165模式2及附加参数、ACT162/163/169的全部状态机。不能据此宣称所有音频行为已与原版一致。

### 4.7 语音（2026-10-11 更正）

旧报告把 `.txt` 的说话人字符串下标当成语音序号，此结论错误。

- `ACT137` 的第二个 int 选择语音场景编号；子脚本也须使用这个编号。

- 从 1002 开始按默认选项追踪到的 10050 个语音事件，均精确命中本地文件。
- 游戏主循环改用这些编号播放，新正文出现时停止上一句语音；缺失文件输出明确日志。

## 背景文件缺失（实战结论）

### 音频时序后续修正

混音读取改为每声道独立的非阻塞管道，防止 ffmpeg 阻塞全部声道及停止指令。循环交给同一个 ffmpeg 的 stream_loop，避免每次循环重启产生间隙。限制 BGM 当前曲与旧曲淡出共两路，-2切换让旧曲15帧淡出。补上ACT162过渡等待、163结束等待、169 SE音量过渡等待；ACT165的第六参数模式2保留原声道并更新音量，不重新播放。BGM无后缀缺失时，附加参数为0选A，否则选B（原版0x406b53→0x460e67）。未做实际听感对照。
